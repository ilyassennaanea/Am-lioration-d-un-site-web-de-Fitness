# Responsive Design : Une technique qui permet à un site web de s’adapter aux différentes tailles d’écran.
- Media Queries : Permettent d’appliquer des styles CSS selon certaines conditions, comme la largeur de l’écran.
- @media : Le mot-clé utilisé pour créer une Media Query.
- min-width : Définit une largeur minimale pour appliquer des styles.
- max-width : Définit une largeur maximale pour appliquer des styles.
- Breakpoint : Une largeur d’écran à laquelle le design change pour s’adapter à l’appareil.
- Mobile-first : Une approche qui consiste à concevoir d’abord le site pour les petits écrans, puis pour les grands écrans.
